# Counter Dapp - Cairo Bootcamp V Week 3

A decentralized counter application built on Starknet with token balance tracking.

## Features
- Increment/Decrement counter by custom values
- Display STRK token balance
- Display USDC token balance
- Auto-connect wallet functionality
- Beautiful gradient UI with loading states

## Tech Stack
- Cairo (Smart Contract)
- React + Vite
- Starknet React
- Starknet.js
- TailwindCSS
